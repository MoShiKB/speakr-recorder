5. Windows helper

Records the whole computer with one click (no share dialog), and works with 7.1 surround headsets, where Chrome's own route cannot record the sound.

Checking…

  1. Open the downloaded Install Speakr Recorder helper.cmd.
  2. If Windows says it protected your PC: More info → Run anyway.
  3. Wait for "Installed", press a key to close, then click Check again.

Needs Python 3.9+ (the installer tells you if it is missing). To remove it, run helper\windows\uninstall.ps1 from the repo.
